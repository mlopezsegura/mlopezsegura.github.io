# mlopezsegura.github.io

Personal portfolio of **Mario López Segura**, full stack developer at Jisap.

**Live:** https://mlopezsegura.github.io

A single static page with no build step and no dependencies:

- `index.html`: content, in English;
- `assets/js/main.js`: Spanish translations, animations and the live repository list from the GitHub API;
- `assets/css/style.css`: styles and CSS animations.

Animations respect the system's *reduce motion* setting. To preview locally, serve the folder with any
static server, for example `python -m http.server`, and open http://localhost:8000.
