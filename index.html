About me

I'm a full stack developer at Grupo Jisap, a livestock, meat and agriculture group based in Lorca, Spain, where we are digitalizing thousands of processes and bringing AI into each of them. My day-to-day goes from the ERP core to the screens people use: Microsoft Dynamics AX and X++, .NET APIs, SQL Server, and Angular and Ionic front ends.

Outside work I love making games travel from a PC to any screen with as little latency as possible. That curiosity turned into a set of open-source projects around Sunshine, Moonlight and WebRTC: from a C++ streaming host to a Samsung TV app and a browser client with a WebAssembly core.

I enjoy the whole stack, from encoder pipelines and network protocols to the last pixel of a user interface, and all the way down to the hardware: I also love tinkering with ESP32 and Arduino boards.

#include <DHT.h>

DHT sensor(4, DHT22);   // data pin on GPIO4

void setup() {
  Serial.begin(115200);
  sensor.begin();
}

void loop() {
  float celsius = sensor.readTemperature();
  Serial.printf("%.1f °C\n", celsius);
  delay(2000);
}

        
from machine import Pin
import dht, time

sensor = dht.DHT22(Pin(4))   # data pin on GPIO4
